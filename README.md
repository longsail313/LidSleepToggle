# Lid Sleep Toggle

一个轻量的原生 macOS 菜单栏应用，用于一键切换 MacBook 的合盖休眠状态。

## 功能

- 常驻菜单栏，不显示 Dock 图标。
- 清楚显示当前是“合盖会休眠”还是“合盖继续运行”。
- 一键切换状态，并使用 macOS 原生管理员认证。
- 每 10 秒自动刷新状态，也可以手动检查；手动检查后会显示明确的结果提示。
- 不安装后台守护程序，不收集数据，不连接网络。

## 安装

从 GitHub Releases 下载 `LidSleepToggle.zip`，解压后将应用移动到“应用程序”。首次启动时，如果 macOS 阻止打开，请右键应用并选择“打开”。

当前发布包使用临时签名，没有经过 Apple 公证，因此首次启动可能出现安全提示。

## 使用

点击菜单栏图标：

- 月亮图标表示合盖会正常休眠。
- 闪电图标表示合盖后系统仍会继续运行。
- 选择菜单中的切换按钮，输入管理员密码即可修改状态。

应用调用的系统命令只有：

```bash
pmset -a disablesleep 0
pmset -a disablesleep 1
```

设置由 macOS 保存，退出应用不会自动更改当前状态。

> 开启“合盖继续运行”后，不要把仍在运行的 Mac 放进包中，以免散热不良。

## 开发

要求 macOS 13 或更高版本。

```bash
make
make test
./Scripts/package-app.sh
```

打包完成后，应用和 ZIP 文件位于 `dist/`。
